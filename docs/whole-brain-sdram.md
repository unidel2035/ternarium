# Whole-brain на Tang Mega 138K Pro — план (трасса B)

Статус: образ данных готов, контроллер памяти — следующий этап.

## Данные

`tools/fly/export_full.py` упаковывает весь коннектом (139 255 нейронов,
5 919 790 тритов) в **fly_full.img — 18.4 МБ**:

```
0x000000  заголовок 256 байт: 'TRNF' v1 N nnz off_W off_C off_R
off_W     веса: CSR data, 2 бита/трит (01=+1, 10=−1)          ~5.92 МБ
off_C     колонки: u16 дельта col[j]−col[j−1], 0xFFFF=escape  ~11.95 МБ
          (escape: следующее слово u32 = полная дельта)
off_R     rowptr: u32 × (N+1)                                 ~0.56 МБ
```

Загрузка образа: openFPGALoader может писать в SPI-флеш платы, либо хост
льёт по UART/PCIe в SDRAM после старта. SDRAM Dock — 32 МБ, образ влезает ×1.7.

## Память

Предпочтение — **SDR SDRAM** (W9825G6KH-класс, 32 МБ, 16-бит шина):
контроллер ~200 строк RTL, полностью реалистичен в open-тулчейне
(yosys/nextpnr-himbaechel/apycula). DDR3 на GW5AST через apycula —
не практичен (нужен vendor-PHY) → вариант отклонён.

## Архитектура matvec-движка v2 (стриминг)

- Такт памяти 100 МГц, такт вычислений 50 МГц.
- За одно чтение u32 — **2 entry** (вес+дельта колонки).
- Конвейер: addr→[SDRAM latency, burst]→decode→xa/xb read→acc.
- Пропускная способность: ~16.6 млн трит/с худший случай
  (1 entry / 3 такта вычислительного домена), т.е. **полный проход
  мозга ≈ 355 мс**; с burst-чтением и предвыборкой x — цель < 100 мс.
- Порог и упаковка x' — как в fly_brain (переносимо 1:1).

## Bring-up чек-лист

- [ ] SDRAM-контроллер: init (200 µs) + REF every 64 ms + ACT/RD/WR/PRE
- [ ] калибровка: чтение паттерна при старте (DQS не нужен для SDR)
- [ ] bridges: W/C/R сегменты → адресный маппинг, стрим CSR-обхода
- [ ] пороговый проход из y-буфера в BRAM (переиспользовать fly_brain)
- [ ] UART-протокол fly_brain без изменений (S/T/D/H)
- [ ] SRAM-тест → SPI-флеш

## Риски

- apycula + SDRAM-пин-тайминги: DRAM-контроллер — тактовая когерентность
  100/50 МГц; начинать с CAST/opensdram-референса под Gowin.
- Первая версия: без burst — 1 entry/такт памяти всё равно даёт < 0.4 с
  на проход мозга.
